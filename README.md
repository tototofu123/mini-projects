# 🎨 Python Sketchbook

[![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white&style=flat-square)](https://www.python.org/)
[![Turtle Graphics](https://img.shields.io/badge/Graphics-Turtle-green?style=flat-square)](https://docs.python.org/3/library/turtle.html)
[![Educational](https://img.shields.io/badge/Type-Lab_Assignment-blue?style=flat-square)](https://github.com/tototofu123/sketchbook-python-lab2-10102023)

An interactive, CLI-driven drawing application built using Python's **Turtle Graphics** module. This project explores fundamental programming concepts including user input handling, conditional logic, and infinite loops to create a digital sketchbook experience.

## ✨ Features

- **⌨️ CLI Menu System**: A robust text-based menu for selecting drawing tools.
- **📐 Geometric Primitives**: Support for drawing lines, rectangles, and circles with user-defined dimensions.
- **🎨 Dynamic Styling**: Real-time control over pen color and fill color.
- **🔄 Transform Controls**: Move the turtle to any coordinate on the canvas and rotate it by specific angles.

## 🛠️ Command Reference

| Command | Action |
| :--- | :--- |
| **`m`** | Move the turtle to specific `(x, y)` coordinates. |
| **`t`** | Rotate the turtle left by a specified angle. |
| **`l`** | Draw a line to specific `(x, y)` coordinates. |
| **`r`** | Draw a rectangle with custom `width` and `height`. |
| **`c`** | Draw a circle with a specified `radius`. |
| **`p`** | Change the pen color. |
| **`f`** | Change the fill color. |
| **`q`** | Quit the program. |
