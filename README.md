## ✨ Key Features

- **🦈 Organic Swarm Intelligence**: Implements the classic Boids algorithm (Separation, Alignment, Cohesion).
- **🎨 Deep-Sea Aesthetic**: Bioluminescent colors and volumetric effects.
- **📐 Custom Instanced Geometry**: Optimized rendering of up to 5,000 "Manta" agents.
- **🎛️ Interactive Controls**: Real-time parameter adjustment via UI.

## 🛠️ Tech Stack

- **Framework**: React 18, React Three Fiber, Three.js
- **State/Styling**: Zustand, Tailwind CSS v4, Leva
- **Automation**: GitHub Actions (CodeQL, Deployment)

## 🚀 Getting Started

1. **Clone the Repo:** `gh repo clone tototofu123/boids-deep-sea`
2. **Install Dependencies:** `npm install`
3. **Run Dev Server:** `npm run dev`
