# Boids: Deep Sea 🌊🐟

A deep-sea themed flocking simulation implementing the **Boids algorithm** with emergent behaviors and high-performance rendering.

## ✨ Features
- **Emergent Behavior**: Simulates separation, alignment, and cohesion.
- **Deep Sea Aesthetic**: Custom visual styles optimized for a dark, atmospheric underwater feel.
- **High Performance**: Built with Vite and TypeScript for smooth browser-based simulation.

## 🚀 Tech Stack
- **TypeScript**
- **Vite** (Build tool)
- **Canvas API** / **WebGL**

## 🛠️ Installation
```bash
npm install
npm run dev
```
