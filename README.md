# SVG Migration Script 🛠️📂

A collection of Python utility scripts designed for batch processing, renaming, and migrating SVG icon libraries (specifically optimized for **Tabler Icons**).

## 📋 Features
- **Batch Migration**: Move and organize large sets of SVG files.
- **Icon Optimization**: Cleans up or modifies SVG attributes during migration.
- **Tabler Icons Support**: Includes specific logic for handling Tabler Icon naming conventions.

## 🛠️ Tech Stack
- **Python 3**
- **PowerShell** (for optimized file system operations)

## 📂 Included Scripts
- `check_and_migrate_tabler.py`: Logic for Tabler Icon transitions.
- `migrate_icons.py`: General SVG migration logic.
- `check_overlap_optimized.ps1`: Performance-tuned script for checking duplicate assets.
