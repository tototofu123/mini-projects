# Jumping Game

A simple infinite platform jumper built with Python and Pygame.

## Controls

- **A / Left Arrow** — Move left
- **D / Right Arrow** — Move right
- **Space** — Restart after game over

## Setup

```bash
pip install pygame
python game.py
```

## How to Play

Jump from platform to platform climbing as high as you can. Platforms scroll down as you rise — miss one and fall off the screen, and it's game over!
