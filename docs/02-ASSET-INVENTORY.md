# Portfolio Duo — Asset Inventory

## Asset principle

Visual assets must be evidence-bearing or clearly labelled as editorial atmosphere. Screenshots, architecture diagrams, hardware photographs, and short screen recordings carry more portfolio value than decorative images. Decorative assets may support the brand but must never pretend to be a project interface or result.

## Asset storage and performance rules

Original editable media lives outside the deployed frontend. The static website references optimized copies only. Use WebP or AVIF for large imagery, provide meaningful `alt` text for evidence images, and avoid autoplay video with sound. Every visual exhibit has a text alternative and a static image fallback.
