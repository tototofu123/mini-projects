# Portfolio Duo — Project Evidence Matrix

This matrix is the gatekeeper against a portfolio that looks polished but says little. No project goes public until its row has enough evidence to make the claim believable.

## Case-study sentence pattern

Use this order in both sites:

> **Problem:** [user] needed [outcome]. **Build:** I created [system] using [relevant stack]. **Decision:** I chose [trade-off] because [constraint]. **Evidence:** [demo, code, screenshot, diagram]. **Limit:** [honest remaining limitation].
