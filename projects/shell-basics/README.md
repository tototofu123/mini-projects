# Shell Basics

A tiny static website that teaches everyday **Windows CMD**, **PowerShell**, and **Linux** commands side by side.

Open `index.html` in a browser. Search, filter by shell, copy a command, and try it in your own terminal.

## Run locally

```powershell
# from this folder
start index.html
```

Or serve the folder with any static server:

```powershell
npx --yes serve .
```

## What Cursor helped create

Cursor scaffolded the HTML, CSS, and JavaScript from a blank folder, then we iterated on search, shell filters, and copy-to-clipboard so the cheat sheet is usable as a beginner lab.
