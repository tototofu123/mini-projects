Same jobs, three shells. Learn the everyday commands for Windows CMD, PowerShell, and Linux side by side.

How to open a shell

  • Windows CMD: press Win + R, type cmd, Enter.
  • PowerShell: press Win, type powershell, Enter. On newer Windows, pwsh is PowerShell 7.
  • Linux: open Terminal, or press Ctrl + Alt + T on many desktops.
