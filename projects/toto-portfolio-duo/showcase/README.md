# Showcase Portfolio — Interactive Exhibit Build Brief

The showcase is a companion experience for visitors who want to inspect the work more deeply. It must feel crafted, but every visual device must explain a real project system, trade-off, or result. It must never become a generic 3D portfolio.

## Experience structure

The landing view is an artifact navigator with six project markers. Selecting a marker opens an exhibit with an interactive system metaphor on one side and a persistent evidence drawer on the other. A visitor can use a pointer, keyboard, or a static fallback to inspect the same content.

## Visual rules

Use graphite surfaces, paper labels, brushed-metal detail, and signal blue only for active connections. Avoid purple gradients, generic cyberpunk effects, fake code rain, auto-playing sound, and long scroll-jacking transitions. The emotional target is a calm design museum with working instruments.

## Showcase success test

A technical visitor should be able to name one real implementation decision for each project after a short visit. A recruiter should always be one click away from the normal portfolio case study.
