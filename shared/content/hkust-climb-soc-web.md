# HKUST Climb Society Web

## One-line story

A public-facing website for the HKUST climbing community, designed around organisation information, access, and responsive delivery.

## What it demonstrates

This project shows frontend execution in a real community context: content structure, responsive experience, and the judgement needed to turn organisational needs into a usable public interface.
