# HKUST Climbing App

## One-line story

A climbing-management system that brings member-facing mobile flows, web administration, and backend services into one product context.

## What it demonstrates

This is the full-stack anchor of the portfolio. It demonstrates that Toto can work across product flows, application interfaces, backend concerns, and an operational domain rather than only creating isolated visual prototypes.

## Evidence to add before public launch

Capture one member flow, one administrative flow, a simplified architecture diagram, and a clear statement of Toto’s personal contribution. Remove private user information from every screenshot.

## Honest limitation
