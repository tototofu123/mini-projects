# OCR MCP

## One-line story

A local OCR model-benchmarking suite that compares vision-language/OCR approaches and routes work through a practical tool-calling workflow.

## What it demonstrates

OCR MCP demonstrates current Python and AI-tooling practice: model comparison, orchestration, local inference considerations, and deliberate routing rather than a generic chat interface.

## Evidence to add before public launch

Show one input-to-result flow, the routing decision, a reproducible invocation, and a small methodology or result table.
